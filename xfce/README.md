# xfce Desktop mit Office und vim

## Übersicht

Liefert einen Linux Desktop mit einigen zusätzlichen
Anwendungen. In diesem Fall vim und Office. Der Desktop
basiert auf xfce. Der Container selbst auf Ubuntu.

## HowTo


- Mit `docker-compose`:


_(Falls schon gebaut):_
```
docker-compose down --remove-orphans
```

_Neu bauen:_
```
docker-compose up -d --build
```
